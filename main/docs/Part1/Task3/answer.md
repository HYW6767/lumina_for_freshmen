# TASK 3 初识 BERT

1. BERT 是什么？BERT 与 Transformer 有什么关系？他的架构有什么特点？他主要用来解决什么问题？

BERT 是一个基于 Transformer 编码器的双向预训练模型，其通过 MLM 和 NSP 进行预训练，且可以通过微调来适应各种下游任务。其与 Transformer 的关系十分紧密：其架构本身是由 Transformer 的 Encoder 堆叠而成，再加上一个任务头来输出。结构特点为：只有编码器，无解码器；拥有双向注意力。其主要用于自然语言的处理，理解自然语言的能力十分强大，主要用于文本分类，抽取式问答，不擅长翻译等生成类任务。

2. BERT 的输入是什么？输出又是什么？

BERT 的输入是**序列**，先用 WordPiece 将文本切成序列，在开始加上 [cls]在每个句子之后加上 [sep]，分成三个向量序列逐元素相加后送入模型，这三个向量序列分别为 Token embedding（表示词元），Segment embedding（表示处于第几句话），Position embedding（表示位置信息）

BERT 的输出取决于任务头，若进行问答任务或标注任务，则将 token 的向量表示输出进输出层，若进行分类任务则将第一个特殊 token[cls]的向量表示输入进输出层。最后通过 softmax/argmax 得出预测结果

3. NSP 是什么？MLM 又是什么？

NSP 和 MLM 都是 BERT 预训练使用的方法，其中，NSP 为“下一句预测”，即在序列中挑出一定量的句子对（包含两个句子），其中 50% 的句子对两句挨在一起，另外 50% 不挨在一起，让其辨别这两段是否为**下一句**的关系；MLM 为将整个序列中的随机一定比例（15%）的 token 其中 80% 替换成一个特殊 token[mask]，10% 替换成一个随机 token，剩下 10% 维持不变，让模型通过上下文猜出原位的 token [mask]和随机 token 替换掉的 token

4. BERT 为什么需要 MASK？如果把 MASK 换成其他东西呢？（如随机 token）

用 [mask]替换原位 token 可以把答案从输入中抹去，防止 BERT 根据原位输入直接输出结果，若将 mask 替换成其他标识符，本质上与用 mask 遮盖原 token 没有区别，若全部替换成随机 token，模型又不一定找得到要替换的位置，且容易破坏上下文

5. BERT 为什么需要预训练？一次性训练完不行吗？

首先，BERT 本身参数量很大，因此需要很多数据对其进行训练，一般下游任务的数据量无法满足其要求，因此需要提前喂入大量数据

其次，预训练可以节省大量重复成本，如果每个任务都单独训练，则每次都需要大量时间和数据去进行训练

最后，预训练可以让模型学会语言理解等与任务无关的通用表示

6. BERT 的预训练是怎样进行的？他的预训练有什么特点？他的预训练是想训练什么东西出来？为什么要采用这样的训练策略？

BERT 的预训练使用 BooksCorpus 和英文 Wikipedia 作为语料训练，需要经过 NSP 和 MLM 两个过程（这两个过程的大致流程已经于第 3 题写出）

特点：自监督，双向，两个任务头共用一个 backbone

预训练目的：让模型学会与任务无关的通用语言表示，使模型拥有将文本映射成带有语义的上下文向量的能力

采用此策略的原因：采用 MLM，训练出 BERT 同时使用左右两侧上下文的能力，使用 NSP 训练 BERT 辨识句子关系的能力

7. BERT 预训练完成后，又如何进行微调？BERT 一般可以做什么下游任务？为什么？

针对要完成的下游任务，给预训练后的 BERT 投喂对应的数据，并接上合适的任务头

BERT 有强大的文本理解能力，主要用于文本分类、抽取式问答等文本理解类任务

由于进行了 MLM 的预训练，BERT 可以理解上下文，又由于经过了 NSP 预训练 BERT 使得能够理解句与句之间的关系，这使得其能轻松地找到文本内符合句意要求的部分

8. BERT 和 GPT 一样吗？请从多个方面（如架构，训练方式，上下文）去谈谈两者的区别

不一样

首先 BERT 和 GPT 虽然都是 Transformer 架构的衍生，但是 BERT 只保留 Transformer 的 Encoder 部分，其强项是对文本的理解，而 GPT 只保留了 Transformer 的 Decoder 部分，其强项是生成文本

训练方式上，BERT 采用 NSP 和 MLM 训练其文本理解和联系上下文能力，GPT 则通过预测下一个词来训练其语言生成和建模能力

上下文方面，BERT 能看到双向的上下文，而 GPT 只能看到上文

9. BERT 为什么不能像 GPT 一样生成一长串文章？

因为 BERT 在训练时使用 MLM，它只学过**完形填空**而没有像 GPT 那样通过预测下一个词训练**读后续写**能力，同时，在本来的 MLM 预测时，BERT 能看到未来的文本，而在生成文章过程中，未来的文本尚不存在，条件与其本来预测的条件不匹配
